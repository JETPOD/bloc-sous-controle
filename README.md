# Bloc sous contrôle

Serious game d'hygiène hospitalière au bloc opératoire : bonnes attitudes, maintien de l'environnement maîtrisé, gestion des alertes.

Jouer : https://jetpod.github.io/bloc-sous-controle/

## Contenu

- 3 modules, 30 situations fictives.
  - M1 « Les bonnes attitudes au bloc » (10) : tenue, masque, barbe, portes, nombre de personnes, sorties, intervenants extérieurs.
  - M2 « Maintenir l'environnement maîtrisé » (11) : classes de risque NF S90-351, fiches de requalification, temps de repos, mode veille, maintenance, contrôles, hygrométrie, traçabilité.
  - M3 « Gérer les alertes » (9) : tableau de supervision simulé (pression, température, brassage, inversion de pression, veille), prélèvement non conforme, ISO fongique, alarmes répétées, travaux.
- Réponses classées : bonne pratique, acceptable, écart de pratique, erreur à risque pour le patient.
- Bilans par module et de parcours imprimables, aide-mémoire des seuils, guide d'animation, page des sources.

## Avertissements

- Prototype pédagogique, situations fictives. Relecture EOH et conseil de bloc requise avant usage institutionnel.
- Ni protocole ni attestation de formation. Le protocole local prévaut.
- Aucune donnée personnelle ; progression en mémoire de page uniquement.

## Sources principales

SF2H 2015 (qualité de l'air au bloc), RFE SFAR-SF2H 2021 (tenue au bloc), SF2H 2024 (efficience énergétique des ZEM), avis SF2H 2018-02, SF2H 2018 (contrôles de l'environnement), NF S90-351 (2013). Liste complète dans la page Sources du jeu.

## Technique

Site statique (HTML, CSS, JavaScript sans dépendance). Mesure d'audience Plausible agrégée, chargée uniquement sur jetpod.github.io/bloc-sous-controle/.
